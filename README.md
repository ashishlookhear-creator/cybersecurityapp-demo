# CybersecurityApp — public demo

An interactive security operations dashboard using fictional data. No sign-in or installation is required.

Try **Incidents**: filter by severity, move an open incident to Investigating, then Resolve it. **Reset demo** restores the examples, and **Export report** downloads the simulated results. Changes live in the current browser page and reset on reload.

This standalone HTML, CSS, and JavaScript demo illustrates the workflow of a separate private Java/Spring Boot project. The public demo has no backend, database, credentials, real telemetry, or external API integration. It does not scan systems or take actions on devices.

Open `index.html` locally or view the deployed site from this repository’s GitHub Pages section.
